# DENM Tools — HLN-AZ (Hazardous Location Notification)

> **Planned** — tools for this message type are not yet implemented.

Will cover parsing, visualization, and compliance checking of
**DENM** (Decentralized Environmental Notification Message) captures,
focusing on the HLN-AZ (Hazardous Location Notification – All Zones) use case.

Applicable specifications (planned):
- **ETSI EN 302 637-3** — DENM message format
- **C-ROADS SUD** — HLN-AZ service and use case definitions
- **C-ROADS MP** — DENM message profile
